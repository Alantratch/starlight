## Como usar esta wiki

Use a busca para localizar um sistema ou navegue pelo setor responsável. Cada ficha deve informar finalidade, link público, responsável e procedimento de solicitação. Onde a documentação recuperada não comprova o dado, a página registra **A validar** em vez de assumir que o cadastro ou o acesso continuam vigentes.
