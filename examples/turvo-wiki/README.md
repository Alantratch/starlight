# Wiki Interna de Turvo/PR

Exemplo estático em Astro Starlight para organizar sistemas e procedimentos institucionais.

```sh
pnpm --filter @example/turvo-wiki dev
pnpm --filter @example/turvo-wiki build
```

O conteúdo inicial é deliberadamente conservador: sistemas foram agrupados a partir do pedido e campos sem fonte recuperada estão marcados como `A validar`. Não publique esta documentação em um repositório público sem revisar o conteúdo e aprovar a visibilidade adequada.
