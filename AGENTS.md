# AGENTS.md

Este repositório mantém o framework Astro Starlight e o exemplo da Wiki Interna da Prefeitura de Turvo/PR.

- Preserve a licença MIT e o código upstream fora de `examples/turvo-wiki`.
- Não adicionar senhas, tokens, padrões de senha, IPs internos, endpoints remotos ou dados pessoais.
- Quando a fonte não comprovar um fato, escreva `A validar` e registre a fonte necessária.
- Execute `pnpm --filter @example/turvo-wiki build` após alterações na wiki.
- Não configurar deploy público automático; a publicação deve ser controlada pelo ambiente local.
